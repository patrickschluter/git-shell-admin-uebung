Git Shell Admin Übung

In diesem Repository wurden vier Shell-Skripte erstellt.

Erstellte Skripte
systeminfo.sh – zeigt Informationen über das System an.
dateiprüfung.sh – prüft Dateien und Verzeichnisse.
projektstruktur.sh – zeigt bzw. erstellt die Projektstruktur.
admin-menu.sh – stellt ein Menü für verschiedene Administrationsaufgaben bereit.
Starten der Skripte

Die Skripte können aus dem Hauptordner des Repositorys mit folgenden Befehlen gestartet werden:

./scripts/systeminfo.sh
./scripts/dateiprüfung.sh
./scripts/projektstruktur.sh
./scripts/admin-menu.sh

Falls die Skripte noch keine Ausführungsrechte besitzen, können diese mit folgendem Befehl gesetzt werden:

chmod +x scripts/*.sh
